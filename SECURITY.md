# Security Policy

## Supported Versions

Please see the following list of supported versions for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities via email. We will acknowledge receipt of your vulnerability report and send you regular updates about our progress.

If you have discovered a security vulnerability, please send an e-mail. All security vulnerabilities will be promptly addressed.
